# LinkedIn Media Master

This document is the final assembly guide for the Stay Safe & Brave LinkedIn showcase.

## Recommended post format

Use **one short video as the primary media asset**. Do not use an AI-generated mockup as evidence of the real application. Historical photographs may appear inside the video if their use is approved.

Target length: **65–75 seconds**  
Format: **16:9, 1920×1080**  
Audio: optional subtle instrumental; the video must work completely without sound.  
Language: English overlays; accompanying LinkedIn post in German.

## Editing rules

- Use real application footage for every product claim.
- Do not use generated UI mockups as if they were screenshots.
- Keep transitions simple: cuts, short dissolves, subtle zoom on still photographs.
- Do not add fake browser/device frames unless they contain real captured screens.
- Avoid startup hype language such as “revolutionary”, “production-ready”, “scalable business” or “live platform”.
- Never imply that example mentors are currently verified/bookable.
- Never show credentials, environment variables, personal user data or private admin records.
- Keep overlays on screen long enough to read once.
- One visual idea per scene.

## Thumbnail / first frame

Preferred:

**FROM STARTUP  
TO PORTFOLIO PROJECT**

Stay Safe & Brave · 2025 → 2026

Use a simple split between a real historical booth image and a real current-product screenshot. Do not use an AI-generated portrait or generated product UI.

## LinkedIn attachment strategy

Primary: final video.

Do not overload the same post with multiple technical diagrams. The post text already contains the story; the video should provide evidence and movement.

The architecture diagram belongs primarily in GitHub and can later be reused in a separate technical post or portfolio page.

## Publication gate

Before publishing:

- final video uses only real product captures for product evidence;
- historical team-related wording matches the approved text;
- no visible personal/private data;
- links resolve;
- live demo is still reachable;
- AI scene works on the deployed environment;
- final post + video have been sent to the former founding team for the promised review;
- no wording suggests an active commercial startup.

## Final caption

Use the German caption stored in `docs/linkedin-showcase/README.md`. Do not add a long hashtag block. If hashtags are desired, keep them limited and relevant:
